# 이항 로지스틱 회귀 품질 모듈

## 역할

이 모듈은 프롬프트에서 추출한 hash-regex 특징을 입력받아, 각 후보 모델의 예상
품질을 `0`과 `1` 사이의 값으로 계산합니다.

입력 특징의 선형 결합을 먼저 계산하고, 그 결과를 sigmoid 함수에 통과시켜
품질 확률로 변환합니다. 따라서 결정식은 선형이지만 출력은 확률인 로지스틱
회귀 모델입니다.

```text
logit[model]
    = intercept[model]
      + sum(weights[model] * standardized_features)

predicted_quality[model]
    = sigmoid(logit[model])
```

후보 모델마다 독립된 기준값과 특징별 영향값을 사용하므로, 같은 프롬프트에
대해서도 모델별로 서로 다른 품질을 예측할 수 있습니다.

## 입력

입력은 hash-regex 특징 벡터입니다. 이 벡터에는 프롬프트의 길이, 형태,
코드·수학·숫자 신호와 부호 있는 어휘 해싱 값이 들어 있습니다.

모듈은 각 특징을 학습할 때 계산한 평균과 척도로 표준화합니다.

```text
standardized_feature
    = (raw_feature - training_mean) / training_scale
```

학습 결과에는 특징의 이름과 순서, 평균과 척도가 함께 저장됩니다. 예측할 때
모듈이 이 값을 다시 사용하므로 학습과 실행에서 같은 기준이 유지됩니다.

## 관측 품질을 이항 데이터로 해석하는 방법

학습 데이터의 각 프롬프트에는 모델별 관측 품질 `q`와 생성 횟수 `n`이 있습니다.
이 모듈은 두 값을 성공 횟수와 실패 횟수로 변환합니다.

```text
successes = round(q * n)
failures  = n - successes
```

예를 들어 관측 품질이 `0.75`이고 생성 횟수가 `4`이면 성공 3회와 실패 1회로
해석합니다. 같은 품질 `0.75`라도 생성 횟수가 `40`이면 성공 30회와 실패 10회가
되므로 학습에 더 강한 근거로 작용합니다.

이 방식은 생성 횟수가 다른 관측값을 모두 같은 무게의 실수 하나로 취급하지
않고, 각 품질 값이 얼마나 많은 관측으로 뒷받침되는지를 반영합니다.

성공만 있거나 실패만 있는 작은 관측에서 예측값이 곧바로 `0`이나 `1`에
고정되지 않도록, 각 행의 성공 횟수와 실패 횟수에 각각 `0.5`를 더합니다.

```text
smoothed_successes = successes + 0.5
smoothed_failures  = failures + 0.5
```

## 학습 목적

모델별 기준값과 특징별 영향값은 이항 음의 로그 가능도를 최소화하도록
학습합니다.

```text
loss
    = -sum(
        smoothed_successes * log(predicted_quality)
        + smoothed_failures * log(1 - predicted_quality)
      )
      + regularization
```

정규화 항은 특징별 영향값이 지나치게 커지는 것을 억제합니다. 기준값에는 이
정규화 항을 적용하지 않습니다. 이를 통해 관측 수가 제한된 상황에서 학습
데이터의 우연한 패턴을 과도하게 따라가는 것을 줄입니다.

## 출력

출력은 후보 모델별 예상 품질입니다.

```text
{
    model_a: predicted_quality_a,
    model_b: predicted_quality_b,
    model_c: predicted_quality_c
}
```

각 값은 해당 프롬프트를 그 모델로 처리했을 때 기대하는 품질 추정값입니다.

## 학습 후 저장하는 값

학습이 끝나면 새로운 프롬프트의 품질을 계산하는 데 필요한 숫자표를
저장합니다.

모델마다 다음 두 종류의 값을 저장합니다.

- 기준값: 모든 특징이 학습 데이터의 평균과 같을 때 사용하는 계산의 시작값
- 특징별 영향값: 프롬프트 길이, 숫자 밀도, 어휘 버킷 등의 특징이 평균에서
  멀어질 때 예상 품질을 어느 방향으로 얼마나 바꿀지를 나타내는 값

예측할 때는 모델의 기준값에서 시작해, 현재 프롬프트의 각 특징과 해당 영향값을
곱한 결과를 모두 더합니다.

```text
logit[model]
    = model_base_value
      + sum(standardized_feature * feature_effect)
```

각 숫자가 어떤 특징에 해당하는지 알 수 있도록 특징의 이름과 순서를 함께
저장합니다. 원래 특징을 학습 때와 같은 기준으로 바꾸기 위한 평균과 척도,
기준값과 영향값이 어느 모델에 속하는지도 함께 저장합니다.

이 값들을 사용하면 학습을 다시 실행하지 않고도 새로운 프롬프트의 예상 품질을
계산할 수 있습니다.

저장되는 값은 전체 학습 데이터에서 계산한 숫자와 이름뿐입니다. 개별 프롬프트,
개별 특징 행, 관측 품질, 생성 횟수는 학습 결과에 저장하지 않습니다.
